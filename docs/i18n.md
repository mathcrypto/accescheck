# Traduction par clés et rafraîchissement

La traduction utilise **i18next 26.5.11**, avec des clés sémantiques stables. Les ressources sont les fichiers JSON correspondants dans `src/locales/fr/` et `src/locales/en/`, répartis par page ou fonction. Par exemple :

```json
{
  "actions": { "delete": "Supprimer mon profil" },
  "saved": { "width": "Largeur minimale confirmée : {{width}} cm." }
}
```

Le code appelle `t('profile.actions.delete')` ou `t('profile.saved.width', { width: 95 })`. Les sources HTML utilisent `{{profile.actions.delete}}`. Le compilateur résout ces références et échappe leur contenu **avant** l’injection des scripts et styles. Une clé absente fait échouer la compilation ; les tests vérifient aussi la parité des clés FR/EN. Aucun parcours du DOM ne cherche des mots français et aucun texte utilisateur n’est réécrit.

Les ressources sont importées avec l’application, sans requête JSON tardive. `initAsync: false` et les ressources déjà disponibles permettent d’obtenir le traducteur avant le rendu. Le serveur choisit immédiatement la version FR ou EN de chaque page. Les valeurs insérées dans les interfaces dynamiques passent par `textContent` ; les valeurs des messages et les identités restent verbatim.

La langue explicite `?lang=fr` ou `?lang=en` prime sur le cookie de préférence `accescheck_lang`, puis sur l’ancienne préférence locale. Le cookie ne contient que le code de langue. Les liens internes conservent ce code. Un petit script en tête de page migre l’ancienne préférence locale avant l’affichage du contenu, si le serveur ne pouvait pas encore la connaître. Changer de langue pendant une consultation conserve l’avertissement avant effacement.

La photo de l’hôpital dispose d’une URL `/assets/hospital-<empreinte>.jpg`, d’un cache immuable et de dimensions explicites. Elle n’est plus un attribut `data:` de plus de 500 000 caractères dans le HTML. Le problème de premier affichage a été reproduit sur mobile, avec réseau et CPU ralentis : image absente pendant la réception de cet attribut, puis français avant l’exécution de l’ancien traducteur en fin de page.
